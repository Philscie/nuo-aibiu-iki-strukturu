# Nuo Aibių iki Struktūrų
Ši knyga kviečia pažvelgti į matematiką kaip į procesą, kuriame pavieniai objektai palaipsniui įgauna prasmę per savo tarpusavio ryšius, o šie ryšiai virsta struktūromis. Kelionė prasideda nuo aibių, tęsiasi per sąryšius, atvaizdavimus ir veda į vientisą matematinės kalbos vaizdą..
